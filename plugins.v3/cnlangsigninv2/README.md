# 国语视界签到V3 (CnlangSigninV2)

美观实用的国语视界（cnlang.org）站点签到助手，MoviePilot V3 规范实现。

## 功能

- 一键自动签到，支持 Cron 自定义周期与随机延迟（防风控）
- 签到心情自动取自一言接口，失败时使用默认文案
- 五种通知样式可选，签到结果实时推送
- 详情页展示账号信息、签到状态、成功率 / 大洋统计与历史记录
- 支持系统代理访问站点
- 浏览器模式：被 Cloudflare 拦截时自动启动无头浏览器过验证、刷新 Cookie 与 UA 并重试
- 账号密码自动登录：登录态失效时自动登录论坛获取 Cookie，无需手动复制
- 验证码自动识别：站点开启登录验证码时自动 OCR 识别（需 `ddddocr`，见下文）

## 配置

| 配置项 | 说明 |
| --- | --- |
| 启用插件 | 开启后按 Cron 周期自动签到 |
| 开启通知 | 签到成功 / 失败时推送消息 |
| 立即运行一次 | 保存后后台立即执行一次签到 |
| 清除历史记录 | 清空本地签到历史 |
| 使用代理 | 通过系统代理访问站点 |
| 浏览器模式 | 被 Cloudflare 拦截时自动过验证并刷新 Cookie |
| 浏览器UA | cf_clearance 与 UA 绑定，填与浏览器一致的 UA，留空则自动记录 |
| 签到周期 | Cron 表达式，默认 `0 7 * * *` |
| 随机延迟 | 格式 `100-200`，签到前随机 sleep |
| 保留历史天数 | 历史记录保留天数，默认 30 |
| 通知样式 | 简约 / 清新 / 科技 / 商务 / 优雅 |
| Cnlang Cookie | 浏览器登录 bbs.cnlang.org 后从请求头复制 |
| 论坛账号/密码 | 可选，配置后登录态失效时自动登录获取 Cookie |

## 远程命令

- `/cnlang_qiandao`：立即执行一次签到（Telegram 命令仅支持英文/数字/下划线，故使用拼音）

## 验证码自动识别（v3.4.0+）

站点开启登录验证码时，插件会用 [ddddocr](https://github.com/sml2h3/ddddocr) 在浏览器模式内自动识别 4 位字符验证码，识别错误时换新验证码重试（最多 4 次，Discuz 每 15 分钟允许 5 次失败）。

**依赖安装**：`ddddocr` 未内置，需在宿主环境可用。Docker 部署时在容器内执行：

```bash
pip install ddddocr
```

> 注意：`ddddocr` 依赖 onnxruntime，体积约几十 MB。若容器 Python 版本过新（如 3.14）导致 onnxruntime 无预编译包安装失败，可暂时改用「浏览器勾选自动登录后手动复制 Cookie」方式（Cookie 有效期约 30 天，期间 Cloudflare 验证由插件浏览器模式自动通过）。

## V3 重写说明（v3.0.0）

- 导入迁移至 `app.sdk.*` 稳定接口，移除 `app.core.*` / `app.utils.*` 等旧路径

- 修复原实现中未判空导致的崩溃（`.get_res(...).text` 链式调用、对 `str` 读取 `status_code` 等）
- 通知模板与详情页卡片重构去重，代码量由约 2300 行降至约 1000 行
